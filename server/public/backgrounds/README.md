# תמונות רקע

תשימי כאן קבצי תמונה (`.jpg`, `.png`, `.webp` או `.gif`) - הן יופיעו אוטומטית ברקע הנע במסכי ההתחברות וההרשמה.

- אין צורך לשנות קוד ואין צורך להפעיל מחדש את השרת - הרשימה נטענת מחדש בכל פעם שהדפדפן טוען את מסך ההתחברות.
- אם התיקייה ריקה (או שהשרת לא רץ), הלקוח יציג במקום זאת איורים גנריים כברירת מחדל - כך שהאתר תמיד נראה טוב.
- מומלץ תמונות ביחס רוחב-גובה קרוב ל-3:2 (למשל 900x600) כדי שהן ייחתכו יפה בכרטיסיות שברקע.
- שמות קבצים באנגלית בלי רווחים עדיף (למשל `waterfall-iceland.jpg`).
